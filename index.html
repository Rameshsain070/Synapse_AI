Architecture

Built on a modern, production stack

Every layer is chosen for reliability, performance, and developer experience.

Backend (synapseai-platform)

  • FastAPI 0.115 on Python 3.13+
  • LangGraph StateGraph with AsyncPostgresSaver
  • mem0ai for persistent memory
  • OpenAI GPT-5/4o + Google Gemini fallback
  • PostgreSQL + pgvector (SQLModel ORM)
  • SlowAPI rate limiting
  • Prometheus + structlog + Langfuse

Frontend (this page)

  • Vanilla JS SPA (no build step required)
  • SSE streaming chat with async generators
  • Full auth flow (register, login, sessions)
  • Task CRUD with AI suggestions UI
  • Semantic search via REST
  • Dark/light theme, mobile responsive
  • Hosted on GitHub Pages

Additional Components

  • React 19 + Vite frontend (synapse-ai-frontend)
  • Next.js 16 + Three.js (unified-web-interface)
  • Azure OpenAI proxy (synapseai-llm-service)
  • Docker Compose for local dev
