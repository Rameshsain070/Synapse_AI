Synapse AI API Reference

Complete REST API documentation for the Synapse AI platform. Built with FastAPI, the API provides intelligent chat, task management, RAG search, and session management.

Base URL

https://your-backend.railway.app/api/v1

Authentication: Most endpoints require a Bearer token obtained from the login endpoint. Include it in the Authorization header:

Authorization: Bearer <your_token>

Quick Start

Get up and running in three steps:

  1. Register an account via POST /api/v1/auth/register
  2. Login to obtain a Bearer token via POST /api/v1/auth/login
  3. Call any endpoint with Authorization: Bearer <token>

Authentication

POST /api/v1/auth/register

Create a new user account.

Request Body

{
  "email": "user@example.com",
  "password": "securepassword"
}

Example

curl -X POST https://your-backend.railway.app/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"securepassword"}'

Response 200

{
  "user": {
    "id": "abc-123",
    "email": "user@example.com"
  },
  "token": "eyJhbGci..."
}
POST /api/v1/auth/login

Authenticate and receive an access token. Uses form-urlencoded body.

Request Body form-urlencoded

username=user@example.com
password=securepassword
grant_type=password

Example

curl -X POST https://your-backend.railway.app/api/v1/auth/login \
  -d "username=user@example.com&password=securepassword&grant_type=password"

Response 200

{
  "access_token": "eyJhbGci...",
  "token_type": "bearer"
}

Chat API

POST /api/v1/chatbot/chat

Send a message to the AI chatbot and receive a response.

Request Body

{
  "message": "What is LangGraph?",
  "session_id": "optional-session-uuid"
}

Example

curl -X POST https://your-backend.railway.app/api/v1/chatbot/chat \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"message":"What is LangGraph?","session_id":"abc-123"}'

Response 200

{
  "response": "LangGraph is a framework for building stateful AI agents...",
  "session_id": "abc-123"
}
POST /api/v1/chatbot/chat/stream

Stream a chat response using Server-Sent Events (SSE). The response is delivered as a series of text chunks.

Request Body

{
  "message": "Explain RAG in detail",
  "session_id": "abc-123"
}

Example

curl -N -X POST https://your-backend.railway.app/api/v1/chatbot/chat/stream \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"message":"Explain RAG in detail","session_id":"abc-123"}'

Response SSE stream

data: {"chunk": "RAG stands for "}
data: {"chunk": "Retrieval-Augmented Generation..."}
data: [DONE]
GET /api/v1/chatbot/messages?session_id=xxx

Retrieve all messages for a given session.

Query Parameters

  • session_id — The session UUID

Example

curl https://your-backend.railway.app/api/v1/chatbot/messages?session_id=abc-123 \
  -H "Authorization: Bearer <token>"

Response 200

[
  {
    "role": "user",
    "content": "What is LangGraph?",
    "timestamp": "2025-01-15T10:30:00Z"
  },
  {
    "role": "assistant",
    "content": "LangGraph is a framework...",
    "timestamp": "2025-01-15T10:30:02Z"
  }
]

Tasks API

GET /api/v1/tasks

Retrieve all tasks for the authenticated user.

Example

curl https://your-backend.railway.app/api/v1/tasks \
  -H "Authorization: Bearer <token>"

Response 200

[
  {
    "id": "task-001",
    "title": "Review PR #42",
    "description": "Review the latest pull request",
    "priority": "high",
    "category": "development",
    "status": "todo",
    "created_at": "2025-01-15T09:00:00Z"
  }
]
POST /api/v1/tasks

Create a new task.

Request Body

{
  "title": "Review PR #42",
  "description": "Review the latest pull request",
  "priority": "high",
  "category": "development"
}

Example

curl -X POST https://your-backend.railway.app/api/v1/tasks \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"title":"Review PR #42","description":"Review the latest pull request","priority":"high","category":"development"}'

Response 201

{
  "id": "task-002",
  "title": "Review PR #42",
  "description": "Review the latest pull request",
  "priority": "high",
  "category": "development",
  "status": "todo",
  "created_at": "2025-01-15T12:00:00Z"
}
PUT /api/v1/tasks/{id}

Update an existing task by ID.

Request Body

{
  "title": "Review PR #42 (updated)",
  "status": "in-progress",
  "priority": "medium"
}

Example

curl -X PUT https://your-backend.railway.app/api/v1/tasks/task-002 \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"status":"in-progress"}'

Response 200

{
  "id": "task-002",
  "title": "Review PR #42 (updated)",
  "status": "in-progress",
  "priority": "medium",
  "updated_at": "2025-01-15T14:00:00Z"
}
DELETE /api/v1/tasks/{id}

Delete a task by ID.

Example

curl -X DELETE https://your-backend.railway.app/api/v1/tasks/task-002 \
  -H "Authorization: Bearer <token>"

Response 204

No content
GET /api/v1/tasks/{id}/ai-suggestions

Get AI-powered suggestions for a specific task, including next steps and priority recommendations.

Example

curl https://your-backend.railway.app/api/v1/tasks/task-001/ai-suggestions \
  -H "Authorization: Bearer <token>"

Response 200

{
  "task_id": "task-001",
  "suggestions": [
    "Break this task into smaller subtasks",
    "Consider setting a deadline for this week",
    "Similar tasks were completed faster with pair programming"
  ]
}
POST /api/v1/tasks/search

Perform a semantic search across tasks using natural language.

Request Body

{
  "query": "tasks related to code review"
}

Example

curl -X POST https://your-backend.railway.app/api/v1/tasks/search \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"query":"tasks related to code review"}'

Response 200

[
  {
    "id": "task-001",
    "title": "Review PR #42",
    "score": 0.94
  }
]

Search

POST /api/v1/rag/search

Perform a RAG-powered vector search across ingested documents and knowledge base.

Request Body

{
  "query": "How does the memory system work?",
  "top_k": 5
}

Example

curl -X POST https://your-backend.railway.app/api/v1/rag/search \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"query":"How does the memory system work?","top_k":5}'

Response 200

{
  "results": [
    {
      "content": "The memory system uses mem0 to store long-term context...",
      "score": 0.92,
      "source": "architecture.md"
    }
  ]
}
